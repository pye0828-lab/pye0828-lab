### 📁 Repository Naming Rule

레포 이름은 **`대상_OS_역할_이름`** 형식입니다.
이름순으로 정렬하면 같은 종류끼리 모이도록 만들었습니다.

| 필드 | 값 | 의미 |
|---|---|---|
| **대상** | `fw` / `mob` / `pc` / `web` / `server` | 펌웨어 / 모바일 / PC / 웹 / 서버 |
| **OS** | `android` / `ios` / `win` / `mac` / `linux` / `py` / `js` | 플랫폼 또는 기술 스택 |
| **역할** | `app` / `tool` / `game` / `lib` / `demo` | 앱 / 유틸리티 / 게임 / 라이브러리 / 샘플 |
| **이름** | `kebab-case` | 프로젝트 이름 |

```
mob_android_app_ff-overlay-translator
pc_py_tool_motionview
web_js_tool_kakaomap-coverage
web_js_tool_googlemap-coverage
```

예: `pc_py_tool_motionview` → PC · Python · 툴 · MotionView
